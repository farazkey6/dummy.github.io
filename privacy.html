Rclone Privacy Policy

Last updated: October 17, 2026

1. Overview

Rclone is used as a privately operated file migration utility for transferring files from Seafile to Google Drive. This policy describes how Google user data is accessed and processed during these operations.

2. Data Accessed

With the user's authorization, Rclone may access Google Drive files, folders, filenames, metadata, and file contents according to the permissions granted during OAuth authentication.

The Google Drive full-access permission may also permit Rclone to create, modify, move, and delete Drive files when instructed by the operator.

3. How Data Is Used

Google Drive access is used exclusively to perform file migration, synchronization, and related file management operations initiated by the authorized operator.

For the intended migration, files are read from Seafile and uploaded into the authorized Google Drive account.

4. Data Storage

OAuth credentials and access tokens are stored in the Rclone configuration on the privately managed server.

File contents are transferred between the configured storage services. Temporary files, caches, and operational logs may be stored locally when required by the configuration.

5. Data Sharing

Google user data is not sold or used for advertising. Files are transferred to storage destinations explicitly configured by the authorized operator.

Data is processed by the relevant storage providers, including Google Drive and Seafile, as necessary to carry out the requested file transfers.

6. Data Security

Connections to Google Drive use Google's OAuth 2.0 authentication and encrypted HTTPS communication.

Access to locally stored credentials is restricted to authorized administrators of the server.

7. Data Retention and Deletion

Transferred files remain in the destination Google Drive account until deleted by an authorized user or administrator.

Local credentials, temporary files, and logs are retained according to the server's operational configuration and can be removed by the administrator.

Google account access may be revoked through the user's Google Account security settings.

8. Google API Services User Data Policy

The application's use of information received from Google APIs is subject to the Google API Services User Data Policy, including the Limited Use requirements.
