Rclone

Private File Migration Utility

About the Application

Rclone is a file management utility used to securely transfer and synchronize files between cloud storage services. This deployment is intended for migrating files from a Seafile server to Google Drive.

Purpose

The application uses Google Drive API access to upload files from an authorized Seafile storage account into the Google Drive account selected by the operator.

How It Works

The operator authorizes access to Google Drive using Google's OAuth 2.0 authentication system. Rclone then uses that authorization to perform operator-initiated file transfers.

Access and Availability

This is a privately operated migration utility. It is not a public file-sharing service and does not offer public account registration.

Privacy

Information about Google Drive permissions, data processing, authentication, and retention is available in our Privacy Policy.
